# html-test

A simple static site experiment.

The deployable page lives on the [`html-page`](../../tree/html-page) branch — a single `index.html` with a `netlify.toml` configured to publish from the repo root.

## Deploying to Netlify

1. In Netlify, **Add new site → Import from Git**.
2. Select this repository.
3. Set the production branch to `html-page`.
4. No build command needed; publish directory is `.`.
